💻 Programs Included
Basic Data Types – Stores and displays student details.
If-Else – Checks whether a student has passed or failed.
Loop and Array – Displays marks of students using an array and loop.
Functions – Demonstrates a simple addition function.
Class and Object – Demonstrates student details using a class and object.
Constructor and Destructor – Demonstrates object initialization and cleanup.
Static Member – Counts the number of objects created.
Inline and Friend Function – Demonstrates an inline getter and friend function.
